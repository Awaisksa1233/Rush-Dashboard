# Rush CRM & Baremetrics Analytics Dashboard

A modern, responsive executive analytics and revenue intelligence dashboard built with React 18, Vite 6, and Tailwind CSS.

## Features
- **Tunnel Throughput Analytics**: Multi-metric visualizer with interior clean dashed target benchmarks.
- **Baremetrics SaaS Intelligence**: MRR, ARR, churn rate, LTV, net revenue churn, and cohort breakdown.
- **Dark/Light Mode Theme Switching**: Sleek glassmorphism UI with real-time responsive data cards.
- **Production Ready**: Optimized Vite 6 build with full Cloudflare deployment compatibility.

## Tech Stack
- **Framework**: React 18 + Vite 6 + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
